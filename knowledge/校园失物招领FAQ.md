# 校园失物招领常见问答（演示版）

## 1. 拾获物品怎么处理
1. 尽量保管原样，不要拆开私人物品
2. 记录拾获地点、时间、物品外观
3. 通过「拾了么」助手登记信息，或送到学校招领中心
4. 贵重物品（证件、电脑、手机）建议尽快交到保卫处或招领中心

## 2. 如何申请认领
1. 提供丢失地点、时间、物品特征
2. 提供可核验独特细节（如壳内姓名缩写、贴纸图案、划痕位置）
3. 由招领中心进行人证核验
4. 核验通过后现场领取并签字

## 3. 为什么要防冒领
仅凭「我也丢了同款」不能直接领取。需要独特细节相互印证，降低冒领风险。

## 4. 招领中心示例信息（演示数据）
- 名称：校园失物招领中心
- 地点：学生活动中心 1 楼 103
- 开放时间：周一至周五 9:00-17:00
- 咨询方式：中心窗口或辅导员转介

## 5. 常见地点
图书馆、二食堂、教学楼、体育馆、宿舍门禁口、快递点

## 6. 失物登记联系方式（重要）
登记拾获或寻物时，联系方式必须为以下之一：
1. 手机号（11 位）
2. 完整学号 + 真实姓名 + 学院（三项均需填写）
可上传物品图片，便于线上辨认。
不再使用「学号后四位」作为唯一联系方式。
本平台服务西安外国语大学（XISU）校园场景。

## 7. 闲置物品交易 / 置换
1. 卖方发布闲置信息时，联系方式默认不公开
2. 买方申请后，平台互换双方联系方式（手机号，或学号 + 姓名 + 学院）
3. 双方自行线下联系，当面确认成色后再交易
4. 平台不代收代付、不担保交易结果
5. 建议在公共场所面交，贵重物品谨慎交易
6. 发布时可上传物品图片，便于线上预览成色

## 8. 信用与公益（演示设定）
- 登记拾获可获得信用激励
- 确认归还后双方可获得正向信用记录
- 闲置捐赠可记入公益行为

- 本知识库为竞赛演示内容，实际以各高校官方规定为准
- 涉及现金、证件等高风险物品，优先线下官方渠道处理
