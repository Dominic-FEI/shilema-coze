怎么用

先用学号注册账号，再进入两大主功能；需要引导时可唤起扣子助手。

  1. 个人主页：学号注册，完善头像、昵称、性别、手机号
  2. 失物招领：浏览信息流 / 搜索 → 点「+」登记（手机号或学号+姓名+学院）并上传图
  3. 闲置交易：浏览 / 搜索 →「+」发布 → 申请互换联系 → 线下看成色
  4. AI 助手：自然语言整理登记信息、核验凭证、生成文案
